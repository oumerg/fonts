# Amharic Fonts Collection

This folder contains a large collection of Amharic and Ethiopic typefaces for desktop publishing, web design, branding, mobile apps, and general graphic work.

The collection includes a wide range of styles such as:

- Classic and traditional Ethiopic serif fonts
- Modern sans-serif fonts
- Display, headline, and decorative styles
- Handwriting and script-inspired designs
- Bold, italic, thin, and variable-weight options
- Fonts suitable for office, signage, education, and digital media

## Included font types

The files in this folder are primarily in `.ttf` and `.otf` formats and include both common and specialized Ethiopian script styles, including many names that reflect Amharic, Geez, and Ethiopic design traditions.

## Suggested use

- Install the fonts on your system to use them in Word, PowerPoint, Photoshop, Illustrator, and other design tools.
- Use display fonts for headings and titles.
- Use serif or regular styles for body text and reports.
- Use decorative styles sparingly for branding, posters, or cultural design work.

## Notes

- Some fonts may be designed for specific visual effects and may not suit all text-heavy use cases.
- Check licensing or source terms if the fonts are intended for commercial work.
- Preview multiple styles before finalizing any design project.

## Quick install

On Windows:

1. Open the font folder.
2. Select one or more `.ttf` or `.otf` files.
3. Right-click and choose Install or Install for all users.

On macOS:

1. Open the font file.
2. Double-click to preview.
3. Click Install Font.

On Linux:

1. Copy the font files into your fonts directory, such as `~/.local/share/fonts/` or `/usr/share/fonts/truetype/`.
2. Refresh the font cache if needed.

## Project purpose

This collection is meant to make Amharic and Ethiopic typography more accessible for designers, students, developers, and anyone working with Ethiopian languages.
